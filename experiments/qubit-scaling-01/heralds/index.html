What each decoder sees

Both decoders receive the same ideal check parities for each shot. Blind matching knows the marginal X/Y flip probability. Heralded matching also receives one binary erasure flag per data site. The flag indicates a site replaced by a uniformly random Pauli in this simulation. Its edge weight is zero, and every unflagged edge receives the correct conditional X/Y weight. The true logical parity and sampled Pauli labels stay with the evaluator.

The archived bath profile supplies separate channels at time 4.00 and 8.08, with erasure probabilities of 60.57% and 23.54%. Each shot has one effective bath opportunity per site, ideal checks, and a free clock-specific frame correction after a pass. The channel draws are independent across sites. Within each clock, the paired comparison measures the effect of providing the flags. Across clocks, the elapsed time and physical channel both change.

Timing protocol

One process on an Intel Core i7-13700HX, with 128-shot batches and interleaved blind and heralded calls. Time includes herald processing and construction of the matching graph for each flag pattern. It excludes bath sampling, syndrome generation, scoring and initial decoder setup. The main scaling study was also running, so host contention can affect absolute times. These runs represent a separate one-round model.
