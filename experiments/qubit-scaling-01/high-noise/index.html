Rotated Z memory at distances 7, 15 and 31, with rounds equal to distance and a fixed parameter of 1% in the provisional circuit-level noise model. Six decoders receive the same 2,048 detector records at each distance. The observable stays with the evaluator.

At distance 31, ordinary matching failed on 801 of 2048 shots. The equal-axis and bath-clock correlated variants failed on 445 and 438 shots, respectively. The bath-clock versus equal-axis comparison had 179 recoveries and 172 regressions.

Protocol

Equal-axis and bath-clock matching both compile correlated matchers using the same idle-channel expansion, with uniform or archived bath-derived Pauli weights. CSS routing sends records above the activity cutoff to native correlated matching. The cutoff uses 1,024 separate unlabeled calibration shots and a 6% target fraction.

Runtime is the median from warm 128-shot calls in separate single-process decoder workers. Runtime includes any required input unpacking. Setup, sampling and scoring occur outside the timer. The main benchmark was also active on the host.
