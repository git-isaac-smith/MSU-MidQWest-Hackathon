# Beating ordinary matching under circuit-level noise

This experiment tests whether a decoder can make fewer logical mistakes and finish a batch faster than ordinary PyMatching on the same machine. The input is a packed Stim detector record. The predicted output is one bit. The scorer separately compares that bit with Stim's actual logical observable. The organizer brief does not specify the final noise file, so this study uses the project's provisional `simple_uniform` circuit-level model. The earlier five-round X-fault experiment uses a different circuit and its rates belong to a separate comparison. [Five-round study](new-approach/POSTERIOR.md)

## Measured winners for Z memory at 0.5%

| Distance | Decoder | MWPM error → decoder error | MWPM → decoder batch µs/shot | Decoder batch µs/round |
| ---: | --- | ---: | ---: | ---: |
| 3 | Posterior lookup | 1.7537% → **1.4850%** | 0.470 → **0.038** | 0.013 |
| 5 | Selective correlated matching | 1.4660% → **1.3713%** | 3.381 → **3.350** | 0.670 |
| 7 | Selective correlated matching | 1.0100% → **0.9400%** | 12.071 → **9.337** | 1.334 |

The three comparisons met their prespecified criteria. The distance-3 lookup prevented 806 net logical failures in 300,000 paired shots. Selective matching prevented 142 and 105 net failures in 150,000 shots each at distances 5 and 7. Approximate paired 95% intervals for the absolute reductions were 0.2384–0.2989, 0.0670–0.1223 and 0.0472–0.0928 percentage points, respectively. The speed margin at distance 5 was small in the main 2,048-shot batches. On 21 fresh 8,192-shot batches per distance, each candidate was faster in all 21. Median paired speedups were 25.20×, 1.13× and 1.30×. These figures depend on batch size and CPU. [Independent timing replication](experiments/circuit-frontier-01/timing-replication.json)

If the error rate matters more than throughput, always using correlated MWPM at distance 7 gave **0.6180%** on the same records and took **31.94 µs/shot**. The candidate with the lowest logical error can change with physical noise, basis and allowed run time. The Pareto table retains methods for which no other method in the same case had both an equal or lower error count and an equal or shorter measured time, with at least one strict improvement. ## Which methods were tested

- **Ordinary and correlated matching.** Ordinary PyMatching connects detection events by minimizing error-chain weight. The correlated implementation can use joint faults that ordinary graph matching treats as separate pieces. Both baselines call the native library in packed batch mode. [PyMatching implementation](https://github.com/oscarhiggott/PyMatching/blob/master/src/pymatching/matching.py) · [Sparse Blossom paper](https://arxiv.org/abs/2303.15933)
- **Posterior lookup and sparse fault cache.** At distance 3, the 24 detector bits index a precomputed answer. The team's existing Walsh–Hadamard transform sums the signed probability of compatible fault histories using the circuit detector error model. The decision uses the more likely logical bit, subject to the compiler's float64 error bound. The new packed inference path indexes the answer directly. This is a Fourier transform of probabilities over binary fault parities. It preserves timing information in the syndrome. At distances 5 and 7 the full table would require an impractical exponential amount of memory. The larger-distance variant caches a bounded list of low-order faults, verifies each full syndrome key, and delegates misses to matching.
- **Selective correlated matching.** The ordinary matching graph splits into components. For a single specified memory observable, only components carrying an edge that flips that bit affect its ordinary matching cost. The decoder identifies those components from the graph. For routine shots it decodes the relevant component. For high-activity shots it supplies the complete, original record to correlated matching. The activity cutoff is the 94th percentile in a separate sample of 8,192 unlabeled syndromes per circuit. Tie choices in ordinary matching can depend on processing order. All comparisons use the actual software outputs. This shortcut uses the known target observable of a memory experiment.
- **Weighted Union-Find.** The compiled single-threaded baseline grows clusters of defects, then peels the resulting forest to extract a correction. Its computational complexity motivates measuring it across distances. Actual wall time depends on implementation, workload and platform. [Delfosse and Nickerson](https://arxiv.org/abs/1709.06218)
- **Temporal low-pass and threshold.** A discrete cosine transform smooths each uninterrupted interior check trace with reflected ends. We retain modes up to 0.20 cycles per round, threshold at 0.5, and feed the resulting binary events to ordinary matching. Initial and terminal slices stay intact. A single data fault can cause a sharp, isolated detection event. Removing that event can erase the evidence for a logical correction.
- **Local pair removal.** A second prefilter joins isolated adjacent events only along real edges of the matching graph. It carries forward the logical parity of each applied correction and gives the remaining events to ordinary matching. This is a local-to-global control. The original renormalization-group and predecoder papers use more elaborate locality and probability rules. [Duclos-Cianci and Poulin](https://arxiv.org/abs/0911.0581) · [Local predecoder paper](https://doi.org/10.1103/PhysRevApplied.19.034050)

AlphaQubit demonstrated the value of learning from spatiotemporal check records on Sycamore data. More recent work combines a learned local predecoder with a global decoder on GPUs. Our CPU measurements compare several independent software implementations. A Reddit discussion about a fast decoder highlighted two issues we address here. We simulate faults throughout the circuit and identify which timing measurements require a complete buffered record. The hardware and workloads in those reports differ from this study. [AlphaQubit](https://pmc.ncbi.nlm.nih.gov/articles/PMC11602728/) · [AI-based predecoders](https://arxiv.org/abs/2604.12841) · [Developer discussion on Reddit](https://www.reddit.com/r/QuantumComputing/comments/1q798bu/i_built_a_baremetal_zeroallocation_qec_decoder_in/)

## How to read the evidence

Stim generates rotated X and Z memories with distance and rounds equal to 3, 5 or 7. The ordinary sweep varies the same nominal physical probability over 0.1%, 0.3%, 0.5%, 0.7%, 1%, 1.5% and 2% at the project's depolarizing, readout and reset locations. Each of the 42 ordinary cases has 20,000 held-out shots. Eighteen additional stress cases at 0.5% add defined faults to the final ancilla readout, the middle round's neighboring ancilla readouts, or neighboring data qubits. Each decoder receives the same augmented model and common shots within a stress case. This measures performance under known stress channels. Unknown drift would require a separate calibration-transfer test.

The primary comparison uses 300,000 independent distance-3 Z-memory shots at 0.5%. Two further comparisons use 150,000 shots each at distances 5 and 7. The protocol specifies the claims before sampling. The primary accuracy test is exact two-sided McNemar at 0.05. The two secondary accuracy tests each use 0.025 to account for both comparisons. The timing criterion is a lower median over five interleaved, warmed batches of 2,048 fresh shots. Other grid comparisons are exploratory. A per-round batch time divides measured time per shot by the round count. A single-record host latency call starts once the complete detector history is available. Neither timing includes hardware acquisition, transport or feedback.

Threshold plots show logical failure per **complete memory experiment** at rounds equal to distance. Error bars and ribbons are 95% Wilson intervals. The accompanying table brackets changes in the ordering of neighboring distances and reports which brackets have disjoint marginal intervals with opposite ordering at their ends. Three distances give finite-size crossover evidence. An asymptotic threshold would require larger distances and a scaling fit. [Circuit-level threshold discussion](https://quantumcomputing.stackexchange.com/questions/33397/effect-of-too-many-syndrome-measurement-cycles-on-surface-code-threshold)

For selective correlated matching in Z memory, the distance-3 and distance-5 curves crossed between **0.5% and 0.7%** physical noise. Distances 5 and 7 crossed between **0.7% and 1.0%**. Both pairs had disjoint Wilson intervals in opposite directions at 0.5% and 1.0%. The hard temporal low-pass filter showed no crossing in this grid and became worse as distance grew. It scored 39.1013% error on the distance-7 confirmation case. The spectral diagnostics and the temporal prefilter answer different questions: a visible frequency component does not identify which individual detector bits can be discarded. [Z-memory sweep](experiments/circuit-frontier-01/threshold-z-ordinary.png) · [X-memory sweep](experiments/circuit-frontier-01/threshold-x-ordinary.png)

The final audit replayed 126 independent Stim archives (1.8 million shots) across 63 cases and checked 441 method/case rows. The public packed-file decoder also reproduced the stored decisions on 10,000 held-out records at each distance.

At distance 7, the diagnostic files contain individual detector event rates, one-sided temporal power, the power of the average trace and an estimate of independent-shot noise in that average. Seven consecutive samples give only three positive Fourier frequencies. A reproducible change in the middle or last round can be visible in these traces. Establishing periodic drift requires longer observations. [Measured circuit results](experiments/circuit-frontier-01/results.md) · [All methods, timings and paired counts](experiments/circuit-frontier-01/metrics.csv) · [Threshold crossings](experiments/circuit-frontier-01/crossings.csv)

The middle-round burst raised the mean-trace power at 1/7 cycles per round from 0.0000079 to 0.000142 on the checks observed in all seven rounds. This deliberately injected burst is a single transient. The frequency plot diagnoses its presence but supplies no evidence of a recurring oscillation. On the distance-7 Z stress shots, selective matching scored 0.880%, 1.205% and 6.055% for final-round, burst and spatial faults respectively. Ordinary matching scored 0.950%, 1.325% and 6.230% on those exact samples. [Detection rates and spectra](experiments/circuit-frontier-01/spectral-diagnostics.png)

### Portable decoder and single-record latency

The exported distance-3 decoder needs 2 MiB to store all 2²⁴ binary decisions, one bit per syndrome. The file is specific to the circuit, noise prescription and detector order. It requires no matching, neural network or LLM during inference. On another 150,000 fresh shots it reproduced all reference decisions. It made 2,233 logical mistakes (1.4887%) against 2,606 (1.7373%) for MWPM. Setup took about 2.46 seconds here.

On 20,000 fresh *individual* complete three-byte records, median CPU latency was **0.50 µs** for the portable decoder and **4.90 µs** for the faster of two MWPM interfaces. The 95th and 99th percentiles for lookup were **1.0 µs** and **3.3 µs**. In 8,192-shot batches the rates were 0.0147 and 0.3967 µs/shot. These timings start at a record already in host memory. A hardware demonstration must also measure acquisition, online scheduling, I/O and delayed shots. ### Retest on the earlier five-round noise model

For the original distance-5 controlled simulation at 0.8% data X faults and 4% readout flips, a separate decoder cached posterior decisions from earlier public detector histories. On 1.5 million new paired shots it made 6,460 errors (0.43067%) versus 6,483 for MWPM (0.43220%). The improvement was inconclusive (*p* = 0.158), and its measured batch throughput was slower. The joint speed and accuracy result above applies to the circuit-level benchmark. [Original-model experiment and timings](new-approach/results/cached-teacher-01/README.md)

## Reproduce and deploy

Run these commands from the repository root using the project Python environment with the `hypergraph` extra installed. Use a fresh output directory for a new study. The stored protocol records package versions, source hashes, calibration seeds, timing seeds and final seeds. The case folders retain the exact Stim circuits, detector coordinates, packed detection events, truth, predictions and timing samples.

```sh
python -m pip install -e ".[dev,hypergraph]"
python -m bascd.circuit_frontier run --smoke --out results/my-frontier-smoke
python -m bascd.circuit_frontier run --out results/my-frontier
python -m bascd.frontier_audit --run results/my-frontier --resample
python -c "from pathlib import Path; from bascd.circuit_frontier_report import write_report; write_report(Path('results/my-frontier'))"
python -m bascd.frontier_timing --run results/my-frontier --out results/my-frontier/timing-replication.json
python -m bascd.circuit_frontier predict --case results/my-frontier/cases/confirmation-d7-z-p0.005-ordinary --method css_routed --detectors input.b8 --output predictions.b8
python -m bascd.portable_lookup predict --table experiments/circuit-frontier-01/portable-d3 --input d3-detectors.b8 --out d3-predictions.b8
```

The file decoder reads detector bytes in the specified circuit's Stim order and writes one predicted observable byte per shot. Observable labels are only needed by the scorer. The audit regenerates every detector and logical bit, re-runs ordinary matching and independently recounts all methods from their archived decisions. Exact seeded replay depends on compatible Stim versions, CPU instructions and sampler batch sizes.
